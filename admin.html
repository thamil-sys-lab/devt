📧 Email Notifications

Every time someone submits a course application, internship application or service request, it is saved to Firebase in real-time. To receive email alerts, set up a Firebase Cloud Function that triggers on Firestore write and sends an email via SendGrid/Nodemailer, or use Zapier (Firestore → Gmail) for a no-code solution.
